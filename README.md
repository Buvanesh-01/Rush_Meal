# Rush_Meal


🍴 Meal Rush - Food Delivery Application

Meal Rush is a Food Delivery Web Application developed using Java web technologies. Users can browse restaurants, view food menus, add items to cart, place orders, and view their order history.

The project also includes a separate Admin Panel to manage users, restaurants, menus, and orders.

🚀 Features
👤 User Side
User Registration
User Login & Logout
Browse Restaurants
View Restaurant Menu
Add Food to Cart
Update & Remove Cart Items
Checkout
Place Orders
View Order History
User Profile
👨‍💼 Admin Side
Admin Dashboard
View Users

Manage Menu Items
View Orders
View Application Statistics

⚙️ How to Run
Clone the repository.
git clone https://github.com/Buvanesh-01/Rush_Meal.git
Import the project into Eclipse.
Create the MySQL database.
Configure the database username and password in the database connection class.
Configure Apache Tomcat.
Run the project on Tomcat.
